# 大气电场采集智能体节点
本作品展示的是大气电场采集智能体节点，基于 AMD Kintex‑7 FPGA 作为主控芯片，搭配 AD9268 高速 ADC 完成模拟电场信号的采集。前端天线拾取大气电场模拟信号，经信号调理后送入 AD9268 实现高速模数转换；FPGA 负责 ADC 时序驱动、并行数据接收、数字滤波、波形特征提取与数据缓存传输。依托 FPGA 并行处理能力，节点实现低延迟实时信号处理，可捕捉雷电事件前后大气电场瞬态变化。本节点可作为分布式探测阵列终端单元，适用于野外雷电电场监测场景。
高速电场信号采集智能节点
摘要	
本作品为高速电场信号采集智能节点，是面向野外雷电电场监测场景设计的分布式探测阵列终端单元。节点以AMD Kintex-7现场可编程门阵列（FPGA）为主控芯片，以ADI公司AD9268双通道16位高速模数转换器（ADC）完成模拟信号的数字化。前端感应天线拾取大气电场模拟信号，经阻抗变换、放大、滤波与电平匹配等信号调理后送入AD9268；FPGA并行完成ADC样时序驱动、高速数据接收、数字滤波、波形特征提取以及数据缓存与以太网传输控制，运行于工控机的上位机软件则负责采集控制、数据落盘、波形显示与回看。节点支持单次测试、触发采集与自适应阈值三种工作模式，集成GPS授时定位与运行温度记录功能，单次采集可完整记录1秒、2000万个采样点的全波形数据。测试结果表明，在20 MSPS采样率下，单次采集的32000个数据包全部正确接收，无丢包、重复与坏包，能够完整还原输入正弦信号，并可捕捉雷电事件前后的电场瞬态变化。节点具有低延迟、可远程运维、便于组网部署的特点，可为雷暴活动监测与雷电预警提供连续、高保真的电场波形数据。

第一部分  作品概述
1.1功能与特性
本节点实现了大气电场模拟信号从拾取、调理、高速数字化到实时处理、存储与显示的完整功能链。在硬件方面，感应天线与信号调理电路将大气电场信号转换为适配ADC输入范围的差分电压，由AD9268完成高速模数转换；FPGA负责ADC时序驱动、并行数据接收、数字滤波、波形特征提取与数据缓存传输，充分发挥其并行处理能力，实现低延迟的实时信号处理。在软件方面，上位机提供test（单次测试采集）、trigger（触发采集）、auto（自适应阈值触发）三种工作模式，支持触发阈值、统计窗口与安全时间等参数设置；采集数据按站点与日期自动归档为二进制波形文件，可进行波形绘制、回看与峰值比对。此外，节点还集成GPS授时定位与芯片运行温度记录功能，并支持通过以太网远程登录运维，可稳定捕捉雷电事件前后大气电场的瞬态变化。


1.2应用领域
雷电是常见的自然灾害之一。在雷云形成及雷击发生之前，近地面大气电场强度会出现显著的异常变化，因此连续观测电场强度及其变化率，是开展雷电监测预警的重要手段。本节点可作为分布式大气电场探测阵列的终端单元，布置于野外重点防护区域，对雷电事件前后的电场瞬态变化进行连续波形记录，为雷暴活动分析、雷电短时预警与雷电定位提供基础数据。其典型应用领域包括：气象台站与雷电监测网的地面电场观测；变电站、输电线路、风电场等电力系统的雷电防护；油气储罐、石化园区等易燃易爆场所的雷电预警；机场、港口、大型桥梁、景区与大型活动场馆的安全保障；以及森林草原、山区等偏远区域的无人值守长期监测。多台节点通过统一站点编码与GPS授时即可组阵，实现区域电场的时空同步观测。

1.3主要技术特点
（1）高速高分辨率采集。采用16位双通道高速ADC，系统按20 MSPS 采样率连续采样，单次采集保存1秒、2000万个采样点，可完整记录电场瞬态过程。
（2）FPGA全并行处理。Kintex-7 FPGA以并行流水线方式完成ADC时序驱动、数据接收、数字滤波与特征提取，处理链路延迟低、调度确定性强。
（3）可靠的高速数据传输。ADC数据经以太网分包传输，单次采集共32000个数据包，上位机按包序号校验并统计重复、乱序与坏包；采用8×40 MB环形缓存，测试中实现零丢包。
（4）自适应触发。上位机支持基于噪声统计的自适应阈值（默认12小时标定一次、5倍RMS、安全时间1小时、幅值钳位32760），在降低误触发的同时不遗漏瞬态事件。
（5）状态同步与远程运维。集成GPS授时定位、芯片温度记录、SSH远程登录与按日期自动归档等功能，适应野外无人值守场景。

1.5主要创新点
（1）面向雷电电场瞬态过程，构建“天线—信号调理—16位高速ADC—Kintex-7 FPGA—以太网”全并行、低延迟的采集处理链路，可对事件前后秒级、2000万点的全波形进行完整记录。
（2）采用基于噪声统计的自适应阈值触发机制，按周期自动标定并设置安全时间，兼顾较低的误触发率与瞬态事件捕捉能力。
（3）终端集成GPS授时、温度记录与远程运维功能，按站点编码统一归档，可直接作为分布式探测阵列终端进行规模化部署。

1.6设计流程
本作品的设计按“需求分析—硬件设计—FPGA逻辑设计—上位机开发—联调测试”的顺序推进：首先依据大气电场信号的特点确定采样率、分辨率与带宽指标；随后完成前端调理、AD9268采样与FPGA核心电路及散热结构设计；接着在FPGA中实现ADC驱动、接收、滤波与缓存传输逻辑，并开发工控机上位机；最后利用DDS信号发生器输出正弦波与任意波，完成采集完整性、波形还原与触发捕获的联调验证。

（1）命令处理模块：解析 test、trigger、auto、value、set interval、set multi、set safe、show等命令并向FPGA下发，其中test完成一次单次采集并绘图，trigger持续监听触发，auto按自适应阈值自动标定并触发。（2）采集接收模块：接收线程按包序号拼接数据，单次采集共32000包，并统计接收包数、重复包、孤立包、坏包、缓存饥饿与保存错误；采用 8×40 MB 环形缓存削峰，套接字接收缓冲区请求64 MiB、实际约95.37 MiB。（3）自适应触发模块：按设定周期（默认12h）依据背景噪声RMS重估阈值，默认取5倍RMS，设置1h安全时间，并将幅值钳位在32760。（4）存储模块：按站点代码与日期分目录（data/sheet/test/YYYYMMDD）归档，波形以“站点码+日期时间_序号.bin”命名保存，每次保存2000万个采样点。（5）波形查看模块：支持波形全览、峰值标注（compare_time_peak）与目录切换。

第四部分  总结4.1 可扩展之处
（1）由单通道扩展为多通道电场同步采集，增加多节点阵列组网与统一时间同步（高精度GPS/北斗授时、IEEE 1588），实现区域电场组网观测；（2）增加4G/5G或卫星通信与云端平台，实现数据自动上传、远程升级与预警信息推送；（3）在FPGA中集成数字下变频、小波变换与事件智能识别等更丰富的算法，进一步降低后端处理负担；（4）完善低功耗设计、太阳能供电与防水结构，适应野外长期无人值守；（5）增加与闪电定位、气象雷达等多源数据的融合接口，提升雷电预警准确率。
4.2 心得体会
本项目从雷电电场监测的实际需求出发，围绕“采得到、传得稳、看得清”三个目标，完成了高速电场信号采集智能节点的方案设计、硬件联调、FPGA逻辑开发与上位机软件开发，团队在工程实践中对高速数据采集系统形成了系统性认识。
在硬件联调阶段，我们认识到电场瞬态信号对采样率和触发机制的要求，确定了AD9268高速ADC与Kintex-7 FPGA的组合。调试中发现，采样时钟质量、ADC输出电平与FPGA接收接口的匹配直接影响数据正确性，需要严格核对SPI配置、时钟相位与数据位对齐；信号调理电路的增益、偏置与抗混叠滤波也必须与ADC输入量程匹配，才能充分利用16位量化范围。
高速数据传输与缓存是本项目调试时间最长的环节。20 MSPS、16位的数据流在秒级采集窗口内产生2000万个采样点，被拆分为32000个数据包传输。初期联调中曾出现接收不及时、缓存饥饿等问题，我们通过在FPGA与上位机两侧分别设置缓存、在接收线程中按包序号校验并统计丢包/重复/坏包，并将套接字接收缓冲区调大至约95 MiB、采用8×40 MB环形缓存削峰，最终实现连续多次采集零丢包。这让我们深刻体会到，高速采集系统的可靠性不仅取决于算法速度，更取决于全链路的缓冲与校验设计。
在触发策略上，真实环境中的背景噪声随天气变化，固定阈值容易误触发或漏触发。我们采用按周期统计背景噪声RMS、以倍数自适应整定阈值并设置安全时间的方案，并在测试中用DDS信号发生器分别输出正弦波与任意波突发，验证了常规采集与瞬态事件捕捉的有效性。
在软件与运维方面，上位机将采集控制、数据落盘、波形绘制与回看分离，按站点代码与日期自动归档，使每次采集都可追溯；针对野外无显示器的场景，我们设计了通过Xshell经SSH远程登录工控机的操作流程，并在每次采集时记录GPS状态与FPGA温度，为后续多节点组网与无人值守运行打下了基础。
通过本项目，我们在FPGA并行设计、高速ADC应用、以太网数据传输、Python上位机开发以及软硬件联合调试等方面都得到了锻炼，也认识到自身在模拟前端设计、仪器标定和结构工艺方面仍有不足。后续将按计划补齐定量测试数据，完善野外适应性设计，推动节点真正走向分布式雷电电场监测应用。
