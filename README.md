# 大气电场采集智能体节点
本作品展示的是大气电场采集智能体节点，基于 AMD Kintex‑7 FPGA 作为主控芯片，搭配 AD9268 高速 ADC 完成模拟电场信号的采集。前端天线拾取大气电场模拟信号，经信号调理后送入 AD9268 实现高速模数转换；FPGA 负责 ADC 时序驱动、并行数据接收、数字滤波、波形特征提取与数据缓存传输。依托 FPGA 并行处理能力，节点实现低延迟实时信号处理，可捕捉雷电事件前后大气电场瞬态变化。本节点可作为分布式探测阵列终端单元，适用于野外雷电电场监测场景。

核心亮点

[高速高分辨率采集] 16位双通道ADC，20 MSPS采样率，单次采集保存1秒、2000万个采样点的全波形数据
[FPGA全并行处理] Kintex-7 FPGA以并行流水线方式完成ADC时序驱动、数据接收、数字滤波与特征提取，处理链路延迟低、调度确定性强
[零丢包可靠传输] 以太网分包传输，8x40MB环形缓存，单次采集32000个数据包全部正确接收，零丢包、零坏包
[自适应触发机制] 基于噪声统计的自适应阈值（默认12小时标定一次、5倍RMS、安全时间1小时、幅值钳位32760），兼顾低误触发率与瞬态事件捕捉能力
[野外无人值守部署] 集成GPS授时定位、芯片温度记录、SSH远程登录与按日期自动归档，适应野外长期运行
系统架构

整体结构
系统由采集节点与工控机两大部分构成：
采集节点：感应天线、信号调理电路、AD9268高速ADC、Kintex-7 FPGA核心、GPS模块、时钟与电源模块
工控机：运行上位机软件（Python开发），负责采集控制、数据存储与波形显示
信号流向
感应天线拾取大气电场模拟信号 → 信号调理电路（阻抗变换、程控放大、抗混叠滤波、单端转差分） → AD9268高速ADC（16位模数转换） → FPGA（ADC时序驱动、并行数据接收、数字滤波、波形特征提取、缓存传输） → 以太网 → 工控机上位机（命令交互、数据包校验、触发判定、波形落盘与显示回看）

硬件组成
模块说明

信号调理模块	对接感应天线，提供高阻输入，完成阻抗变换、程控放大、抗混叠滤波与单端转差分处理
AD9268采样模块	双通道16位、最高125 MSPS流水线型ADC，1.8V供电，FPGA通过三线SPI配置
FPGA核心模块	Kintex-7器件，多层高密度PCB，集成配置存储、复位、时钟与电源去耦电路
通信模块	以太网物理层芯片、网络变压器，FPGA经RGMII接口与物理层连接
GPS与状态模块	SP3232电平转换，授时定位与温度采集，为每次采集提供时间、位置和状态信息
电源模块	12V外部输入，经多路DC-DC、LDO稳压转换为5V/3.3V/2.5V/1.8V/1.2V等
机械设计	一体化铝合金机箱，表面散热鳍片，内置风扇强制风冷，实测FPGA温度36.4~43.4度

软件系统

FPGA端：采用硬件描述语言实现ADC采样驱动、并行接收、数字滤波、特征提取与以太网传输逻辑
上位机端：Python开发（fpga_host_v6.py、waveform_processor_v1.py），运行于Ubuntu 18.04系统
远程运维：通过Xshell经SSH登录工控机，协议SSH，端口号60255（端口后三位为工控机编号）

工作模式说明

test	单次测试采集，完成一次采集并绘图显示，适用于系统联调验证
trigger	触发采集模式，持续监听触发条件，满足阈值时启动采集，适用于捕捉特定事件
auto	自适应阈值触发模式，按周期（默认12h）依据背景噪声RMS重估阈值，自动标定并触发，适用于野外无人值守长期监测

快速开始
硬件连接
1. 连接感应天线至采集节点信号输入接口
2. 用网线连接采集节点以太网口与工控机以太网口
3. 连接GPS天线至采集节点GPS接口
4. 接通12V电源
软件部署
1. 工控机安装Ubuntu 18.04系统
2. 安装Python 3运行环境及依赖库（matplotlib等）
3. 将上位机程序fpga_host_v6.py、waveform_processor_v1.py部署至工控机工作目录（/media/lrg/DISK/LY）
运行测试
1. 远程PC通过Xshell SSH登录工控机（主机IP: 120.253.53.150，端口: 60255）
2. 切换至工作目录：cd /media/lrg/DISK/LY
3. 启动上位机：python3 fpga_host_v6.py
4. 在上位机主菜单中选择test命令进行单次采集测试
5. 采集完成后查看波形绘制结果与统计信息（丢包数、重复包、坏包等）

测试结果
采集完整性测试
在trigger模式下可连续完成触发采集，每次采集均带有GPS状态与时间戳。针对任意波突发事件，波形查看器可全览秒级瞬态波形，并标注峰值与持续时间，验证了系统对雷电瞬态事件的捕捉能力。
状态记录
每次采集均记录GPS授时定位状态与FPGA温度（36.4~43.4度），波形文件按站点代码与日期时间自动归档（data/sheet/test/YYYYMMDD/站点码+日期时间_序号.bin），便于事后追溯与分析。
扩展方向
1. 多通道组网：由单通道扩展为多通道电场同步采集，增加多节点阵列组网与统一时间同步（高精度GPS/北斗授时、IEEE 1588），实现区域电场组网观测
2. 远程通信：增加4G/5G或卫星通信与云端平台，实现数据自动上传、远程升级与预警信息推送
3. 算法增强：在FPGA中集成数字下变频、小波变换与事件智能识别等更丰富的算法，进一步降低后端处理负担
4. 低功耗设计：完善低功耗设计、太阳能供电与防水结构，适应野外长期无人值守
5. 多源数据融合：增加与闪电定位、气象雷达等多源数据的融合接口，提升雷电预警准确率
